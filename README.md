# SafarShield
### Smart Tourist Safety Monitoring and Incident Response System
A smart tourist safety system which combines location monitoring, geofencing, global positioning, distance calculation and artificial intelligence to detect potentially unsafe situations and assists travellers faster during any incident.

## Problem

Tourists, especially solo travelers, may face safety risks while travelling through unfamiliar locations.

## Proposed Solution

SafarShield aims to provide:
- Location-based safety monitoring
- GPS-based tracking
- Geofencing
- Risk-level identification
- Personalized safety messages
- Tourist assistance during potential incidents

## Technologies
- Python
- MySQL
- Google Maps / Maps API
- GPS
- AI API(Gemini)
